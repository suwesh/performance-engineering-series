# PyTorch Profiler Captures

### <a href="https://www.kaggle.com/datasets/suwesh/beneath-the-tokens-gpu-profiling">gpu-profiling/profiles/torch/</a>
Matched PyTorch Profiler artifacts, including worker traces, frontend traces, and profiler summaries.

These traces expose runtime annotations such as generation contexts, model execution, sampling, and MTP proposal processing.

### <a href="https://www.kaggle.com/datasets/suwesh/beneath-the-tokens-gpu-profiling">gpu-profiling/profile_client_runs/torch/</a>
Client-side records generated during profiler-instrumented requests.

### <a href="https://www.kaggle.com/code/suwesh/pytorch-rq4-analysis-ipynb">pytorch_rq4_analysis.ipynb</a> and <a href="https://www.kaggle.com/datasets/suwesh/beneath-the-tokens-gpu-profiling">gpu-profiling/result-analysis/</a>
Analysis scripts, derived tables, notebooks, and supporting outputs used to produce the results reported in the technical report.
